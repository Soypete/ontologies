# AGENTS.md

RDF/OWL ontology repository for open-source tech ontologies. Contains Turtle (.ttl) files for learning software development concepts.

## Directories

- `software/` - Course/procedure ontologies (PKO-based)
- `thesaurus/` - SKOSthesauri for testing inference
- `education/` - Learning ontologies (L2WS, edu)
- `social/` - Topic thesauri (Twitch topics)
- `coordination/` - Coordination T-box for multi-agent wiki workflows
